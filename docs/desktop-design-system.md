# نظام التصميم لعميل Halaqa Desktop

## الهدف

يوحّد هذا الدليل واجهات عميل WPF حول تجربة عربية هادئة وواضحة تدعم خط **Cairo** واتجاه القراءة من اليمين إلى اليسار، مع الحفاظ على قابلية القراءة في نوافذ سطح المكتب المختلفة دون ربط الواجهة بمكتبة تصميم خارجية.

## الطبقات المشتركة

| الطبقة | مصدرها | الاستخدام |
|---|---|---|
| الألوان | `Shared/Presentation/Themes/Colors.xaml` | الخلفيات، النصوص، الحالات، والحدود. |
| الطباعة | `Shared/Presentation/Themes/Typography.xaml` | Cairo للنص العربي وخط المصحف للنص القرآني فقط. |
| المكونات | `Shared/Presentation/Themes/Controls.xaml` | البطاقات، الأزرار، الحقول، القوائم، والجداول. |
| الأيقونات | `Shared/Presentation/Controls/AppIcon.cs` | رموز Windows القياسية دون تبعية خارجية. |

## قواعد التخطيط

تستخدم صفحات المحتوى هوامش خارجية `28,24`، وتمنع أشرطة التمرير الأفقية في الشاشات النصية والنماذج. تستخدم البطاقات الخارجية النمط `AppElevatedCard`، بينما تستخدم المجموعات داخل الصفحة النمط `AppSectionCard`. يجب عدم وضع آخر زر داخل `DockPanel` من دون تحديد موقعه، لأن خاصية التعبئة الافتراضية قد تمدده ليملأ المساحة المتبقية.

تعتمد صفحات الدخول على `WrapPanel` حتى تنتقل البطاقات إلى صف مستقل عند تضييق النافذة. أما الشاشات كثيفة المحتوى مثل الجلسة المباشرة، فتستعمل أعمدة نسبية وحدود عرض دنيا مدروسة مع حد أدنى للنافذة يساوي `960×640` للحفاظ على قابلية تشغيل الوسائط والمصحف معاً.

## قواعد النص والحقول

تُعرض تسميات الحقول فوق المدخلات باستخدام `CaptionText` بدلاً من الاعتماد على `ToolTip` فقط. تستخدم عناوين الصفحات `DisplayTitle` أو `PageTitle`، وعناوين الأقسام `SectionTitle`. يظل البريد الإلكتروني والتواريخ والأوقات وأرقام الهاتف في اتجاه `LeftToRight`، بينما يبقى السياق العربي والشرح في اتجاه `RightToLeft`.

## الأزرار والحالات

يستخدم الإجراء الأساسي النمط الافتراضي `AppPrimaryButton`. تستخدم الإجراءات الأقل أهمية `AppSecondaryButton` أو `AppQuietButton`، ويستخدم الإجراء الحساس `AppDangerButton`. لا يجوز استخدام اللون وحده لتوصيل المعنى؛ يجب أن يكون نص الزر واضحاً، وتبقى الحالة المعطلة مرئية بمستوى شفافية أقل.

## قائمة التحقق قبل دمج شاشة جديدة

| المعيار | التحقق المطلوب |
|---|---|
| العربية | `FlowDirection="RightToLeft"` وخط Cairo موروثان. |
| الاستجابة | لا توجد عروض ثابتة للحاويات الرئيسية؛ تستخدم `MaxWidth` أو أعمدة نسبية عند الحاجة. |
| التمرير | لا يحدث قص رأسي، والتمرير الأفقي معطل للصفحات النصية. |
| الحقول | لكل حقل تسمية مرئية واتجاه مناسب للبيانات اللاتينية أو الرقمية. |
| الحالات | تظهر رسائل الخطأ والنجاح في بطاقة واضحة متباينة. |
| الجودة | يمر الحل عبر `dotnet restore --locked-mode` و`dotnet build` قبل الدمج. |
