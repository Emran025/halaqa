# اعتماد مرجع shafeea_teach

## القرار المصحح

مشروع `quran-halaqa` هو **خدمة ويب Laravel** تملك عقد OpenAPI والحالة الرسمية. أما `halaqa` فهو **WPF Application بلغة C# يعمل على سطح Windows** ويتصل بالخدمة عبر HTTPS وREST. لا يُنقل Flutter إلى المشروع ولا يصبح `shafeea_teach` مصدراً لعقد API؛ بل هو مرجع للأصول الثابتة، نموذج بيانات المصحف المحلي، أنماط الأخطاء، وفكرة التخزين المحلي المتزامن.

| مصدر المرجع | ما يُعتمد في Halaqa WPF | ما لا يُنقل |
|---|---|---|
| `assets/QuranV3.sqlite` | قاعدة مصحف ثابتة للقراءة المحلية، تُنسخ في أول تشغيل ثم تفتح للقراءة فقط. | لا تُعامل كقاعدة بيانات للحالة التعليمية الرسمية أو كبديل عن API. |
| `assets/fonts` | خطوط عرض عربية وخطوط المصحف بعد إدراج الملفات المختارة بوضوح داخل المشروع. | لا يعتمد التطبيق على Flutter FontFamily أو أسماء Flutter أو على ملفات لا تُراجع رخصتها. |
| `core/error/failures.dart` | فصل أخطاء البيانات، الشبكة، الخادم، cache، وغير المتوقعة؛ يترجم إلى `AppError` في C#. | لا ينسخ كود Dart أو نوع `Either` نفسه. |
| `app_database.dart` | المبادئ: migrations، تفعيل foreign keys، صف عمليات معلقة، UUID، وقت تعديل، وحالة مزامنة. | لا ينقل جدول المستخدمين أو الحلقات أو تتبع الحضور محلياً؛ هذه متصلة بالشبكة في عقد Quran Halaqa. |
| `quran_local_data_source_impl.dart` | التهيئة الكسولة الآمنة، النسخ مرة واحدة من asset، الاستعلامات المرتبة، وفشل cache الصريح. | لا ينقل sqflite أو أسماء Dart أو تنفيذ Flutter. |

## SQLite في عميل WPF

يوجد ملفان محليان منفصلان في `%LocalAppData%\Halaqa\Data`:

```text
QuranV3.sqlite     ← نسخة مهيأة من Assets\Quran\QuranV3.sqlite، للقراءة فقط
halaqa-local.db    ← قاعدة التطبيق الصغيرة: mistake_outbox وsync_metadata فقط
```

يُفتح `QuranV3.sqlite` باستخدام `Microsoft.Data.Sqlite` بوضع read-only بعد نسخه بطريقة ذرية من ملفات التطبيق عند أول استخدام. الجداول المرجعية اللازمة لعرض المصحف هي `Quran` و`Sora` و`Tracking_Unit`. ولا يعد الملف مرجعاً لحالة المصحف الرسمية في الجلسة؛ تبقى `PUT /sessions/{sessionId}/mushaf-state` في API هي مصدر الحقيقة.

تخزن عمليات الأخطاء غير المتزامنة في جدول `mistake_outbox` في `halaqa-local.db`. تحمل كل عملية `client_operation_id` و`session_id` و`task_id` والحمولة JSON وحالة المزامنة ووقت الإنشاء وآخر خطأ. لا تخزن كلمات مرور أو بيانات الطلبات الخاصة أو ملفات المستخدمين محلياً.

## قواعد الخطوط

تضاف الأصول المختارة من المستودع المرجعي إلى `Assets/Fonts` مع ضبط CopyToOutputDirectory. يستخدم خط واجهة عربي مرخص ومناسب للـ UI، بينما يستخدم خط المصحف فقط داخل `MushafPageViewer`. عند اختلاف الترخيص أو عدم وجود ملف رخصة بجانب الخط، لا ينشر الخط خارج المستودع ولا يدرج في حزمة إصدار قبل موافقة صاحب الحق.

## نمط الأخطاء في C#

يمتد `AppErrorKind` ليشمل `Data` و`Cache`. تعني `Cache` تعذر نسخ قاعدة المصحف أو فتحها أو قراءة سجل صالح منها، بينما تعني `Data` payload محلياً فاسداً أو غير قابل للتحويل. لا تترجم هذه الأخطاء إلى خطأ شبكة ولا تمسح قاعدة المصحف تلقائياً؛ تعرض رسالة قابلة للفهم وخيار إعادة التهيئة المصرح به.
