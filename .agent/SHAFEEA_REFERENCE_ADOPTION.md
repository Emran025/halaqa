# سياسة أصول قراءة المصحف المحلية

## النطاق والحدود

هذه الوثيقة تصف فقط الأصول المدرجة داخل مستودع `halaqa` وكيفية استعمالها محلياً. لا تعد أي مستودعات أو تطبيقات خارجية مرجعاً لتنفيذ عميل WPF، ولا تملك عقد API أو المسارات أو DTOs أو حالة الجلسة الرسمية. المصدر الملزم لعقد الخادم هو Laravel وفق [مرجع العقد](CONTRACT_REFERENCE.md).

وجود `QuranV3.sqlite` أو خطوط عرض المصحف داخل العميل يثبت توفر أصول قراءة محلية فقط. لا يثبت وجود جلسة مباشرة أو WebRTC أو WebSocket أو حالة مصحف رسمية، ولا يحل محل API.

## ملفات العميل المحلية

يوجد ملفان منفصلان في `%LocalAppData%\Halaqa\Data`:

```text
QuranV3.sqlite     ← نسخة مهيأة من Assets\Quran\QuranV3.sqlite، للقراءة فقط
halaqa-local.db    ← قاعدة تطبيق صغيرة: mistake_outbox وsync_metadata فقط
```

يفتح `SqliteQuranLocalDataSource` قاعدة المصحف بعد نسخ ذري من أصول التطبيق. تستخدم هذه القاعدة للمحتوى الثابت. ولا يجوز تخزين ملفات المستخدم أو كلمات المرور أو طلبات التسجيل الخاصة أو حالة تعليمية رسمية فيها. تظل حالة المصحف الرسمية، عند تنفيذ رحلة جلسة قابلة للتشغيل، خاضعة لمسار Laravel المعلن `PUT /sessions/{sessionId}/mushaf-state`.

## خطوط المصحف

الخطوط الموجودة تحت `Assets/Fonts/QuranPages` أصول معبأة داخل العميل. يختار `QuranPageFontFamilyConverter` المورد الموافق لرقم الصفحة عند استخدام مسار القراءة المحلي. يحتفظ المشروع بملف الترخيص المصاحب للأصول في مجلدها، ولا تنقل هذه الأصول إلى مصدر قانون أو API أو منطق جلسة.

لا يعلن عقد Laravel الحالي حقلاً لرموز العرض الصفحي في مخطط `Ayah`؛ فهو يعلن `text` و`words`. لذلك يبقى العرض الخاص بالأصول المحلية مستقلاً، ولا يجوز الادعاء بأن استجابة HTTP البعيدة توفر تطابقاً بصرياً أو ترميزياً حتى يعلن العقد ذلك صراحة.

## الأخطاء المحلية

يخزن `halaqa-local.db` عمليات الأخطاء المؤجلة في `mistake_outbox` مع `client_operation_id` و`session_id` و`task_id` والحمولة وحالة المزامنة ووقت الإنشاء وآخر خطأ. وجود هذا outbox لا يمثل واجهة أخطاء مكتملة ولا يثبت مزامنة حية ناجحة؛ لا توجد طبقة Presentation أو رحلة غلاف لها في نقطة المراجعة الحالية.

## قاعدة تعديل الأصول

عند تغيير قاعدة المصحف أو الخطوط أو القارئ المحلي، يراجع المطور الملفات المضمنة والرخصة المصاحبة وسلوك `SqliteQuranLocalDataSource`، ثم يشغّل بوابة الجودة. لا ينسخ كوداً أو يفترض واجهات أو يتبع بنية تطبيق خارجي. أي تعديل في DTO أو repository أو مسار HTTP يتطلب مراجعة OpenAPI Laravel الحالي أولاً.
