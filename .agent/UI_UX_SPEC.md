# تصور الواجهات وتجربة المستخدم

## مبادئ التجربة

اللغة الافتراضية عربية مع **RTL كامل**، بينما تقبل الحقول التي يجب أن تبقى لاتينية مثل البريد والرمز والمعرّفات اتجاه LTR محلياً. ينبغي أن تكون الواجهة هادئة وواضحة، ذات تسلسل بصري يعرض المهمة التعليمية الحالية قبل الأدوات الثانوية. تستخدم جميع الشاشات مساحة محتوى موحدة، شريط تنقل جانبي متكيفاً مع الدور، شريطاً علوياً للحساب والإشعارات وحالة الاتصال، ومنطقة تنبيه مرئية لا تعتمد على اللون وحده.

| المبدأ | التطبيق |
|---|---|
| وضوح الحالة | كل عملية تبين Loading أو Success أو Empty أو Error أو Offline Cache أو Pending Sync. |
| احترام الخصوصية | بطاقات المتقدمين قبل القبول تعرض الملخص العام فقط؛ لا توجد حقول حساسة مخفية في ViewModel أو Tooltips. |
| وصولية | تباين كافٍ، نصوص قابلة للقراءة، Tooltips للأيقونات، اختصارات لوحة المفاتيح، وتركيز مرئي. |
| إعادة استخدام | الحقول، البطاقات، الجداول، حالات الفراغ، شريط الحالة، الحوارات، وإجراءات التأكيد Controls مشتركة. |
| المعنى قبل الزخرفة | لكل رمز تسمية أو Tooltip؛ تستخدم أيقونات Material Design SVG من المكتبة بدلاً من صور متفرقة. |

## رحلة الحساب الأولى

تبدأ شاشة الترحيب برسالتين متساويتين: «تسجيل الدخول» و«إنشاء حساب». عند إنشاء الحساب يختار المستخدم الدور مرة واحدة ويشاهد وصفاً موجزاً لما سيطلب منه. تسجيل الطالب Wizard منظم إلى: الحساب والبيانات الشخصية، التواصل والمستوى، أوقات الحضور، خطة المتابعة، ثم اختيار كود معلم اختياري ومراجعة. تسجيل المعلم ينظم المعلومات الشخصية، الخبرة والمؤهل، والوثائق الاختيارية، ثم المراجعة. ينشأ `client_operation_id` عند بدء الإرسال ويظل ثابتاً حتى يتحقق نجاح أو إلغاء صريح، لمنع تكرار الإنشاء عند ضغط المستخدم أو فقد الاتصال بعد الإرسال.

عند نجاح تسجيل الدخول أو التسجيل، تحفظ الجلسة المشفرة وتحمّل `GET /me` لتأكيد الدور. يوجه المستخدم إلى لوحة تناسب دوره. عند 422 تعرض الأخطاء بجانب الحقول، وعند 409 تعرض رسالة تكرار/تعارض مفهومة مع منع إرسال متسرع جديد.

## شاشة المصحف والجلسة

تستخدم شاشة المصحف تخطيطاً من ثلاث مناطق: شريط معلومات الجلسة والمهمة، مساحة المصحف الأساسية عالية القراءة، ولوحة جانبية قابلة للطي للمهام والأخطاء والملاحظات. تظهر حالة الصفحة: «متصل»، «من cache»، أو «تحتاج اتصالاً للتحميل». تعرض العلامة المحلية غير المتزامنة برمز منفصل مع نص `بانتظار المزامنة`؛ لا يزول الرمز إلا بعد رد الخادم. تُظهر التعارضات كبطاقات قابلة للمراجعة ولا تُحل بصمت.

في الجلسة المباشرة تفصل واجهة الاتصال بين حالة REST الرسمية، القناة الداخلية، وحالة الاتصال المباشر. عند `direct_connection_unavailable` تظهر رسالة صريحة بخيار إعادة المحاولة أو إنهاء آمن؛ لا تقترح الشبكة وسيطاً أو خدمة فيديو بديلة.

## مكتبة المكونات المشتركة

| المكون | الغرض |
|---|---|
| `AppShell` | الإطار المشترك، الاتجاه، الشريط العلوي والتنقل. |
| `AsyncStateView` | تحميل، خطأ، فراغ، ومحاولة مجددة بتجربة موحدة. |
| `FormField` و`ValidationSummary` | تسمية حقل، رسالة تحقق، مساعد، ودعم LTR عند الحاجة. |
| `StatusBadge` | حالة مورد أو مزامنة أو اتصال، بنص ورمز. |
| `ConfirmDialog` | تأكيد إجراءات الرفض والحذف والإنهاء. |
| `PagedDataGrid` | قوائم API المقسمة دون تسريب DTO. |
| `SyncIndicator` | يلخص Pending وConflict وFailed للأخطاء. |
| `MushafPageViewer` | عرض صفحة محفوظة بمفتاح الإصدار والصفحة، مع تمييز كلمات تفاعلي. |

## نظام المظهر

تكون السمات في `Shared/Presentation/Themes`: ألوان دلالية قابلة للوصول، Typography عربية أولاً، مسافات ومقاسات موحدة، وقوالب أدوات التحكم. تكون الأيقونات من حزمة SVG/Material Design في `Shared/Presentation/Icons` أو من مورد المكتبة فقط. يمنع إدراج SVG مجهول الترخيص أو نسخ رموز موزعة داخل كل View.
